# DS2_vis_proj
Data visualization through shiny app

Tab 1 (numerical analysis)
  The user chooses two numerical variables and a graph of the relationship is provided.
  The scatter plot helps reveal potential relationships between economic and demographic variables
  
Tab 2 (regional analysis)
 Bar plot of regions where the user picks a numerical variable for the y axis.
 This tab offer the user insight into the economic condition of each region.
